# Focus Mode

A modern, responsive mobile productivity app featuring a **Focus Mode / Time Blocker** with a stunning glassmorphic modal overlay. Built with React, TypeScript, Tailwind CSS, and Framer Motion.

## Features

- **Dark Mode Task Dashboard** — A clean daily task list with categorized items, completion tracking, and productivity stats
- **Glassmorphic Focus Modal** — A frosted glass overlay with backdrop blur that dims the background for maximum concentration
- **Animated Circular Timer** — A 25-minute Pomodoro-style countdown with an SVG progress ring and smooth animations
- **Interactive Controls** — Pause/Resume and End Session buttons with tactile feedback
- **Ambient Effects** — Breathing glow animations and gradient shadows for a calming focus environment
- **Fully Responsive** — Mobile-first design wrapped in a realistic device frame

## Tech Stack

- React + TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- Lucide React Icons
